# ComfyUI Ikki Pack

A collection of custom **ComfyUI** nodes focused on improving workflow quality of life, speeding up repetitive tasks, and making complex workflows easier to build and maintain.

This pack is designed to grow over time with practical utilities that solve everyday problems rather than replacing existing nodes.

## Current Nodes

### 📷 Load & Crop

Load an image and crop it using configurable dimensions and positioning.

Useful for:

* Preparing datasets
* Creating consistent image sizes
* Fast image preprocessing

---

### 🔲 2x2 Grid Crop

Automatically splits an image into four equally sized tiles.

Great for:

* Tile processing
* Upscaling workflows
* Regional editing
* Dataset generation

---

### 🔀 Text Box Switch

Switch between multiple text inputs without constantly reconnecting nodes.

Useful for:

* Prompt testing
* Workflow presets
* A/B comparisons

---

### 🧩 Text Combiner

Combine multiple text inputs into a single prompt.

Perfect for:

* Modular prompting
* Prompt building
* Organizing positive prompts

---

### 📋 LLM Prompt Parser

Parse structured prompts generated by LLMs into usable workflow inputs.

Ideal for:

* AI-assisted prompting
* Structured prompt pipelines
* Automation workflows

---

### 📚 LoRA Stack Loader

Load multiple LoRAs from a single configurable stack instead of wiring individual loaders.

Makes large LoRA workflows cleaner and easier to manage.

---

## Installation

Install directly through the **ComfyUI Registry** or clone into your `custom_nodes` directory.

Restart ComfyUI after installation.
